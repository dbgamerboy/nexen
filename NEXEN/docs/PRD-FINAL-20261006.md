# NEXEN PRD, final build (2026-10-06)

Supplements the 2026-10-04 `PRD.md`, which stays unchanged. Status: draft from findings, owner has not accepted it.

## Product
One app named NEXEN, one executable `NEXEN.exe`, one front door: MARVIN. No version numbers in visible names (decision 20261006-one-app-no-version-names).

## Purpose
AI infrastructure whose output is money: paid clipping, service work (Upwork, Fiverr), organic dropshipping content, YouTube production, AI persona content.

## In scope
1. MARVIN chat, routing, `nexen_decide`, identity rule (JARVIS always means MARVIN).
2. Recursive learning and novel learning, first priority.
3. Seven memory pools, the shared Obsidian vault, one findable note base.
4. Vector DB and RAG over the vault and over `F:\05_AI`.
5. Money lanes: lead finder, service offers, clipper (paid or research only), content pipeline, Higgsfield from existing credits.
6. Reliability: circuit breaker, resource and thermal governors, watchdogs, STOP file.
7. Approval queue for every external effect: post, send, spend, accept terms.

## Out of scope
Personal life modules, benefits tools, games, music hardware, camera bridges, biometric logging, unrelated installers. They move to Archive, not deleted.

## Refused by design
Ban evasion, fingerprint spoofing, account farming to beat caps, mirroring other people's content. Modules built for these are archived and never wired.

## Acceptance
- `NEXEN.exe` starts, serves the core on 8788, MARVIN answers from the local brain.
- No file in the final tree reads `F:` except the read-only ingest source `F:\05_AI`.
- Each kept module has a passing test with bad cases, one real-input run and an inspected output.
- Status words: queued, prepared, tested, connected, running, published, paid.
