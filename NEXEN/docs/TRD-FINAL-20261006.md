## Design
- `paths.py` is the only file with a drive letter. Settings: `NEXEN_HOME` (`H:\NEXEN-FINAL`), `NEXEN_VAULT`, `NEXEN_INGEST_SRC` (`F:\05_AI`, read only), `NEXEN_VECTOR_DIR` (G: Drive vector DB), `NEXEN_DATA`.
- Core: FastAPI on 127.0.0.1:8788 (`nexen.py`, `nexen_hub.py`).
- MARVIN brain: `nexen_decide` rules, then model routing, local Ollama fallback.
- Middleware (routing, resource and thermal governors, circuit breaker, ROI calculator, QA gate) registers inside the core.
- Memory and RAG: seven pools, vault note base, Qdrant client on the G: vector DB. Old ingest disabled and archived. New ingest starts from `F:\05_AI`.
- Packaging: `NEXEN.exe` starts core, loop and watchers using only `paths.py` settings.
- Safety: STOP file halts loops, approval queue gates external effects, rules engine checks every post, spend, clip and account action.

## Build method
1. Copy kept modules into `NEXEN-FINAL`, originals untouched.
2. Rewrite F: references to `paths.py` settings.
3. Test each module with bad cases, one real input, inspect the output.
4. Build the exe and run from it.
5. Commit and push once tests pass and GitHub is logged in.
